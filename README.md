# alien-vanguard
Jogo de tiro 3D sci-fi desenvolvido em HTML5 e Three.js, ambientado em uma arena cyberpunk com névoa e iluminação dinâmica. O jogador controla um soldado de elite armado com um revólver futurista, enfrentando hordas de mutantes alienígenas que ficam cada vez mais numerosas e agressivas a cada onda.
